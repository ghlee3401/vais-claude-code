# Do revision 8 — explicit QA handoff byte contract

## 변경

Review Attempt 12에서 independent-QA 판정은 PASS였지만 compact handoff가 비공개 3KB 제한을 초과해 자동 저장되지 않은 계약 결함을 보완했다. Design의 규모별 3KB/5KB/8KB 한도와 fail-closed 정책은 유지했다.

| 영역 | 구현 결과 |
|---|---|
| Single source | assignment 생성과 automatic handoff 검사가 같은 `QA_HANDOFF_LIMITS`를 사용 |
| Public contract | independent-QA `outputContract`에 규모별 UTF-8 hard limit을 직접 포함 |
| Safety margin | compact/standard/extended target을 2KB/4KB/6KB로 함께 제공 |
| Output discipline | raw JSON-only, repo-relative path/receipt 참조, 로그·화면 내용 복사 금지 |
| Failure handling | oversize handoff에서 `SendMessage` 재개·수동 저장 우회를 금지하고 fail closed |
| Scope | public API·상태 전이·3KB 설계 한도·formal workload·adapter 의미는 변경 없음 |
