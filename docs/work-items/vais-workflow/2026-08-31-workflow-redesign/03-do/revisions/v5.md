# Do revision 5 — Subscription-native evaluation runner

## 변경

Design revision 5에 따라 formal cohort의 dollar budget 제한을 제거했다. production v2 runtime과 `workflowV2.mode: shadow`는 변경하지 않았다.

| 영역 | 구현 결과 |
|---|---|
| Claude invocation | no-cap 모드에서 `--max-budget-usd`를 전달하지 않음 |
| Cost policy | cohort·run·adapter manifest에 `subscription-no-dollar-cap` 결속 |
| Timeout | 양쪽 각 provider turn에 동일한 900,000 ms 상한 적용·증거화 |
| 비용 telemetry | provider list cost는 계속 raw evidence에서 재계산하되 Quality·EFF·중단 조건에서 제외 |
| Backward compatibility | 명시적 `--max-budget` 입력은 `provider-list-cost-cap` 진단 계약으로 계속 검증 가능 |
| Trusted schema | `live-shadow-evidence` 2.2에서 cost policy와 timeout을 cohort/adapter 조건으로 검증 |
| Isolated project | 양쪽 byte-identical seed에 `workflowV2.mode: enforce`를 포함해 v2 managed entry 활성화 |
| Cohort identity | 실행마다 128-bit nonce를 evidence와 ID에 결속해 stage가 같아도 새 cohort ID 보장 |
| 품질 observer | 취소 시나리오 ID·전체 manifest 개수를 강제하지 않고 `취소` evidence를 canonical `book-cancel` 역할로 정규화 |
| 공정성 불변 | canonical workload, prompt adapter, stage, model, effort, tool profile, 순서, 격리, no-replacement 유지 |
