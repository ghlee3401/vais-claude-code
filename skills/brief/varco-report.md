# VARCO 기술 보고서 양식 (문서형)

## 이 양식이 하는 일

`template/report.html` 은 **빈 양식 문서**다. 새 보고서를 만들 때 이 파일을 **복사해서** 내용만 채운다. 양식을 새로 그리지 않는다.

```
cp -r skills/brief/template <작업 폴더>/<보고서명>
# 그 안의 report.html 을 편집한다 (assets/ 는 그대로 둔다. deck-stage.js·image-slot.js 는 덱 전용 — 문서형만 만들 땐 지워도 된다)
```

브라우저로 열면 좌측 목차 + 본문 문서다. 브라우저 인쇄(Cmd/Ctrl+P)로 A4 세로 PDF가 나온다 (목차는 인쇄에서 자동 숨김).

## 절대 바꾸지 말 것 (양식의 정체성)

1. **레이아웃 골격** — 좌측 268px sticky 목차 + 본문 max 900px. `.wrap` 그리드 구조와 `@media print` 블록을 건드리지 않는다.
2. **토큰** — `:root` CSS 변수 값. 색을 새로 만들지 않는다 (허용 색은 아래 표가 전부).
3. **번호 체계** — h2 는 `<span class="num">N</span>`, h3 는 `N.M`. 목차(nav)의 번호·앵커와 항상 일치시킨다.
4. **doc-head** — 키커 / 제목 / 부제 / 메타(과제·작성·보고일·상태 배지) 구성 고정. 하단 2px ink 경계선 유지.
5. **figure 프레임** — 모든 차트·다이어그램은 `<figure>` 프레임 안의 **인라인 SVG** (외부 이미지·라이브러리 금지). 캡션은 `그림 N.` 으로 시작.

## 구성 요소 — 무엇을 쓸지 고르기

스켈레톤의 섹션·요소 중 내용에 맞는 것만 남기고 나머지는 삭제한다. 자리표시자(`○○`)를 남기지 않는다.

| 요소 | 언제 쓰나 |
|---|---|
| `.lead` | 각 섹션 첫 문단 — 섹션이 답하는 질문/결론 한 줄 |
| `.callout.key` | 보고 전체를 관통하는 핵심 원칙·요청 사항 (문서당 1~2회) |
| `.callout.why` | 의사결정 근거 "Why · 한 줄 요약" |
| `.callout.dec` | 오해를 막는 보충·참고 |
| `.callout.todo` | 보고 전 확정할 항목 — 최종본에서는 비우거나 삭제 |
| `ul.b` | 요점 나열 — `① 제목` + `small` 부연. 맨불릿 금지 |
| `table` | 대안 비교(채택 행 `tr.pick`)·스펙·이슈 목록. 3열 이하 우선 |
| `figure` + SVG | 파이프라인·구조도·막대 비교 등 — 스켈레톤의 두 예시를 복제·변형 |
| `.pill` | 상태 칩: `g`(개선·완료) `a`(진행·중간) `p`(높음·주의) `n`(중립) |

부족한 유형이 필요하면 **가장 가까운 요소를 복제해 변형**한다. 새 컴포넌트를 발명하지 않는다.

## figure(SVG) 제작 규칙

- `viewBox` 기준 폭 760~1000px, 텍스트 11~14px, 블록은 `rx:9~12` 라운드 + 1.4px 테두리.
- 단계 그룹은 연면 배경 밴드(`#F4F4FE` 등) + 라벨(`① 그룹명`)로 묶고, 최종 산출만 그라디언트 채움.
- 화살표는 공용 `marker`(`#8a98a8`) 재사용. 색은 토큰 표의 색만.
- 값·축·기간 라벨을 SVG 안에 명기 — 그림만 보고 결론이 읽혀야 한다.

## 내용 작성 규칙 (덱과 공통)

- 한국어 중심. 섹션 키커·라벨은 영문 대문자 한두 단어.
- 숫자에는 **항상 기준**을 붙인다: 집계 기간, 목표값, 산출 방식.
- 미달 지표는 숨기지 않고 원인과 대응을 함께 적는다. 리스크는 담당·기한 있는 것만.
- 이모지 금지. 느낌표 금지. 결론 먼저(두괄식) — 개요 첫 문단에 전체 결론 세 문장.
- 자리표시자(`○○ 과제`, `○○○`, `00/00`)는 **전부** 실제 값으로 바꾼다.

## 마무리 점검

- [ ] 자리표시자·예시 문구가 하나도 남지 않았다
- [ ] 목차(nav)의 번호·제목·앵커가 실제 섹션과 일치한다
- [ ] 모든 수치에 기준(기간·목표·산출 방식)이 붙어 있다
- [ ] figure 캡션이 `그림 N.` 으로 시작하고 번호가 순서대로다
- [ ] todo 콜아웃이 최종본에 남아 있지 않다
- [ ] 브라우저 인쇄 미리보기에서 표·figure 가 잘리지 않는다
