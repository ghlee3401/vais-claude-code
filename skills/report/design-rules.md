## 금지 패턴 8 (self-critique 체크리스트)

| # | 금지 | 대체 |
|---|------|------|

## 타이포 스케일 (고정)

`12 / 14 / 17 / 22 / 28 / 40px` (ratio ~1.28). CSS 변수 `--fs-xs ~ --fs-xxl`.
- 헤드라인: brand display 폰트, 700 이하. 본문: brand body 폰트 400/600.
- 국문 폰트 스택 fallback: `"Pretendard", "Noto Sans KR", -apple-system, sans-serif` (brand 폰트 뒤에).

## 차트 색상 공식

1. 시리즈 1개: `--color-primary`
2. 시리즈 2~3개: primary + primary 의 명도 ±25% 변형 + `--color-muted`
3. 시리즈 4개+: 이 문서를 만들지 말고 데이터를 분리하라 (차트 하나에 4+ 시리즈 금지)
4. 강조 1개 + 나머지 회색(`--color-muted` 60% 투명) 패턴 우선 — "전부 색칠" 금지
5. 축·격자: `--color-hairline`, 라벨: `--color-muted`, 값 라벨은 데이터 옆에 직접 (범례 최소화)

## 레이아웃

- 콘텐츠 폭: 보고서 `max-width: 760px` 중앙 정렬 (본문), 표·차트는 `920px` 까지 돌출 허용
- 여백: 8px 그리드 (`--sp-1~8` = 8/16/24/32/48/64/96/128)
- 슬라이드: 16:9 (1280×720 기준), 안전 여백 64px, 제목은 상단 고정 위치 (슬라이드마다 튀지 않게)
- 표: 헤더 굵게 + hairline 행 구분만 (세로선·얼룩말 배경 금지), 숫자 우측 정렬

## 인쇄 (PDF 변환)

- `@media print`: 배경색 유지 (`print-color-adjust: exact`), `break-inside: avoid` (표·figure·슬라이드)
- 보고서 A4 세로 / 덱은 슬라이드 = 1페이지 (가로)

## 검증 방법 (self-critique 실행 절차)

생성 직후: (1) 금지 8항 각각 위반 검색 (grep 가능: gradient/emoji/동일 클래스 연속) → (2) 본문·배경 대비 4.5:1 이상 확인 → (3) 가장 긴 제목·셀의 오버플로 확인 → 위반 수정 후 `QA: n/8 통과` 보고.
