# VAIS 응답 스타일

- VAIS phase 작업 중이면 응답 첫 줄에 phase 표시: `📋 plan` / `🔧 do` / `✅ review`
- 결론 먼저, 상세는 뒤에. 코드 블록에 언어 명시, 파일 경로는 `path/to/file:line`
- 한국어 기본, 기술 용어는 원어. 간결하고 실용적으로
- phase 완료 시 마무리는 3줄 이내: 요약 + 다음 단계 제안 (`/vais {action} {feature}`)
